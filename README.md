# Wilds Talisman Calculator

A fan-made Monster Hunter Wilds talisman legality + exact-odds calculator.
Live at https://talisman.kiwieditor.com/

Pick up to 3 skills and a decoration-slot layout: the tool checks the
combination against the game's 29 talisman templates and 288 pool entries,
then returns the exact probability, expected appraisals and grind time.
Includes TU4 meta builds for all 14 weapons, each bound to its ideal
talisman.

Plain static site — vanilla HTML/CSS/JS, no build step, no tracking.
Not affiliated with CAPCOM.
